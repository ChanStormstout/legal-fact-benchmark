# 文献与选型依据

核查日期 2026-09-29。重点近期窗口 2024-09-29 至 2026-09-29，保留最接近的经典算法。全文核读表示实际查看所列章节，不表示通读所有证明、复现实验或穷尽该领域。以下为 Codex 的核查；Pro 自述的阅读范围保存在单独网页记录。

此前广泛调查见 [独立文献核查](../project-wide-research/独立文献核查.md)，包含法律因素发现、法律知识图谱、本体归纳、检索、ILP、假说发现、论证、形式化、查询导向清洗等主题。它是背景地图；本轮在决定算法的近邻上补读具体方法。

## 研究裁决

1. 采用已有算法比重新命名一套“LLM检查流程”更合理。A需要落实准入，B需要落实搜索和集合目标，C需要落实推理语义。
2. 单纯结合来源、关系、符号执行不够支撑原创性。可能的贡献在法律状态与身份约束下的有效产出、代价和可复用性，仍需实验。
3. 新旧方法都能获得相同信息后，收益可能消失。方案中的每项优势都保留对应的否决实验。
4. 论文阅读支持机制选择，不证明本地数据质量、专家共识或端到端收益。本轮数据审计和机制验证应与论文成绩分别报告。
