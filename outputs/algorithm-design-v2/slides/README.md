# 8页会议材料

- `Legal_AI_Algorithm_Design.pptx`：英文正文，图形和表格可编辑，每页含中文speaker notes与文献来源。
- `Legal_AI_Algorithm_Design.pdf`：与最终PPTX渲染一致的8页阅读预览。为保持字体与版式，PDF使用高分辨率页面图像，编辑和复制文字请用PPTX。
- `中文讲稿.md`：逐页解释算法步骤、为什么选它、何时应换方案，约10–12分钟。
- `Core_Framework.drawio`：可编辑的总框架源文件。SVG是矢量导出，PNG和PDF为阅读预览。

图中判决与规则均为构造示例，不能当真实法律依据或项目实验结果。完整实现和强替代比较见上级目录《算法设计方案.md》。
