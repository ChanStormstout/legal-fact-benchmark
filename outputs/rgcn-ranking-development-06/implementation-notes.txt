Relational representation and comparison interface (before training)

Input path: permitted facts and fixed question -> needs, proposed facts, objects and status-bearing relational assertions; 14 original authorities -> conditions, scope and exceptions; both sides produce candidate links. Input-graph review cannot read use/preference references. Citation validity establishes location only.
Supervision path: identical sources -> uses for all14 units -> deterministic selection of at most16 pairs -> preferences -> independent source review. Disputed, tied, incomparable, unknown and unlocatable items do not enter directed loss; lower priority is not irrelevance.

Seven node types: need, fact, object, relation assertion, authority, condition and candidate link. Left/right endpoints have distinct edge types. No unconditional object shortcuts or shared status nodes. Unknown relations retain nodes/unknown features without affirmative endpoint edges. Candidate links indicate possible analytical relevance only.
Speaker, court level, polarity and assertion status use one-hot features. Stage, qualifiers and unknown text use fixed32-dimensional signed lexical hashing plus an unknown mask. Authority/case IDs are addresses, not features. Hashing loses semantics, a limitation of these fixed lightweight features.
R-GCN uses two16-dimensional layers with two bases per layer. Neighbors normalize by relation degree. Reverse edges have separate types for information flow, not reversed legal truth. Readout separately mean-pools needs/facts/objects/relations/authorities/conditions/links. Relation features enter readout directly; endpoint information can also propagate. Mean pooling preserves distributions, not exact logical execution.
B uses18 transparent features and regularized linear preference loss; C/C0 share them. Need coverage deduplicates need_id rather than rewarding condition count. C0 keeps projection/pooling/readout and trains separately with neighbor messages disabled. Relation parameters remain initialized/regularized but do not affect C0 predictions; distinguish total/effective parameters.
Case graphs are independent. Fold scaling fits only the other five cases. Shared authority text is visible; held-out labels never enter loss. Two fixed seeds are used; main seed20261004 supplies downstream outputs, and the other is not for selection.
Use200 Adam updates, learning rate0.003, L2=0.001. Average pairwise softplus loss within each case, then across training cases so cases with more preferences do not gain weight.
