## 已确认的失败及原因边界

1251841/C 的第 39 次请求（bundles-0）返回 HTTP 200，约 5.38 秒后结束。正文只有 1,149 个字符，JSON 停在字符串内部；流中有 `[DONE]`，没有非空 finish_reason，也没有 usage。没有出现本地超时、空白或重复保护触发；请求输出容量为 65,536 token。这次不能归因为达到阶段 token 上限。

对全部 39 份实际原始 SSE 逐字回放，新旧解析所得正文、完成状态及用量完全一致：38 份正常、1 份仍为 STREAM_INCOMPLETE。因此没有证据说明旧解析器丢掉了本次答案。缺少服务端日志，尚不能区分上游生成提前结束、网关异常或结构化解码故障。请求 schema 的基本结构排查未发现直接矛盾，也不能据此排除服务端 schema 支持问题。

旧版把请求失败、未知用量和服务不可用共用停止状态；遇到未知用量就停止整个批次，导致独立第二案未派发。费用核对要求本身必须保留；可以修复的是把费用许可与单案失败分别表示，不能通过把未知费用记为零来继续。
