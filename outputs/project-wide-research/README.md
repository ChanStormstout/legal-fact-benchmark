## 本轮独立审查纠正的关键问题

- 谓词类型相同与同一真实事件是两种判断；原始实例、案件内绑定和出处始终保留。
- 缺失见证不能当作事实为假；候选解释全部错误不能当成普通未知。
- 全局一致解释下的支持界与逐案极值之和不相同；求解界只保证显式候选集合内的条件结果。
- 稳健优化场景主问题给上界，完整最坏情形求解给当前可行解下界；普通贪心保证不能直接搬用。
- 下游复核、类别定义修订、集合最大最小目标都有明确先例，不能直接当新颖贡献。

本地数据只读核查为 6,954 条记录，不能据文件名确认法律子领域，也没有已验证的干净结果标签。原文件未修改。建议下一步是小规模原文审计与专家规范校准，然后运行约 90 个案件组的分阶段先导实验；预算与样本量均待实际耗时和数据质量校准。
