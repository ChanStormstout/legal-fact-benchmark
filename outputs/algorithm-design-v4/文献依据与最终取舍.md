## 搜索范围与阅读边界

主时间窗为 2024 年末至 2026-09-29，同时保留直接相关的稍早基础工作。检索覆盖：开放信息抽取与规范化；主动聚类与新类别发现；定义修正与模式归纳；谓词发明与程序学习；受约束子群发现；法律因素、规则获取、非单调论证；法律知识图谱。使用论文原站、ACL Anthology、NeurIPS/ICLR/IJCAI/PMLR、arXiv、作者页面及论文参考文献追查。未用 Reddit 或二手摘要支持方法选型。

这是跨方向的定向文献调研，不是注册过检索协议的系统综述，也不声称搜全近两年所有相关论文。下面区分核读方法、初筛和采用；未复现任何作者代码。v3 的方法报告记录了此前十项近期工作的阅读与取舍，本文件保留补查范围，并加入本轮最终选择。

本轮具体搜索词组包括 `knowledge graph canonicalization`、`schema induction`、`active generalized category discovery`、`relational concept learning`、`predicate invention`、`logical rule induction`、`subgroup discovery`、`legal factors`、`legal rule extraction`、`legal abductive reasoning`，搭配 2025/2026；进一步追查 KGGen、GraphJudge、UniPred、NRI、ICAIL 2025 论文及作者列表。

## 本轮补核及影响

- [KG-MDL 原文](https://arxiv.org/html/2309.12908)，重读 §4 表示、编码、搜索及覆盖限制。其节点可共享、边不重叠是图编码选择，不等于我们的多字段断言记录已有现成编码器。我们首版选择记录不重叠，主体/合同可共享；不把它包装成新压缩原理。
- [Snor 原文](https://eda.rg.cispa.io/pubs/2025/snor-vanleeuwen%2Cvreeken.pdf)，核读 §3–5 编码、覆盖、搜索及 §6 对照结果。重叠需要选择新增覆盖的机制，不是取消不相交限制；实验不是所有数据集都改善。首版不采用复杂重叠覆盖。它仍是将来确认简单编码不足后的有根据备选。
- [ASPIC+ tutorial 原文](https://journals.sagepub.com/doi/10.1080/19462166.2013.869766)，复核 §3.5 的 last-link、攻击/反驳和 §4 的一致性条件。最后可推翻规则可能是集合，不能简写成最后执行一步；首版只运行声明支持的受限片段，不能承袭完整框架的全部保证。

这些是成熟机制的实现核查，未把它们冒充近两年新论文。近期论文改变候选取得、定义修订和反馈的设计；确定性连接、编码和论证继续使用有明确语义的已有方法。

## 独立方案与 Pro 评审后的最终决定

Pro 用时约22分钟返回完整答复，并在答复中明确区分自己核读与附件阅读记录。本地保存了完整请求和答复；不能据它显示搜索过多少网页就声称精读了同等数量论文。

| 决定 | 采用理由与限制 |
|---|---|
| A 增加用途依赖阻断 | 补上“限定虽然保存，但计算时被忽略”的实际漏洞。默认作用域保守，需要原文审阅或已批准规则才能缩小；不能称形式化已保证语义正确 |
| 随机审计从原文段落采样 | 只查已抽出的事实会漏掉零抽取、被排除和高置信系统性错误 |
| B 真实片段作主搜索，各意图各自修正 | 避免宽泛概念靠覆盖击败具体意图。限量短查询补漏；不是完整搜索保证 |
| S 首版采用记录不重叠的可解码近似 | 撤回上一轮重叠token与旧v2 MILP的默认推荐。复杂性集中到语义修正，G保留所有适格关系，不让压缩筛选成为法律筛选 |
| C 按每条规则的政策处理未知例外 | 修正 Pro 上一轮“一律gate”的建议。默认论证的IN与例外事实未知可同时存在，输出必须说明默认依赖 |
| 研究贡献只提出一个可证伪假设 | 用途级阻断与原文修复是否在同预算保留更多正确见证；依赖传播和LLM验证本身均不是原创主张 |

不另加“双方一致即正确”的确认轮：本轮回复已实质回应关键分歧，关键传统语义已补核。实际法律解释和本项目优势仍需要独立审阅与实验。

## 最终选型结论

A 采用定义约束的开放类别归纳与版本修正；B 采用有来源的关系种子、受限概念提议和局部程序修正，并将描述发现与有标签的关联学习分开；C 采用法源规则卡、桥接需求、独立翻译测试和可追溯论证。保留精确关系执行，是因为对象绑定与计数需要确定语义，不是因为经典算法天然优于新方法。

新工作改变了候选从哪里来、错误怎样定位、类别怎样修正以及反馈如何使用。没有采用某套完整模型，可能是缺少它要求的监督或其输出不能直接表达本任务，不是因为“任务不同”就否定全部机制。首版不同时加入所有有趣模块；每个新增组件必须对应一个明确失败原因。
