# Preserved v1 evidence

`archive-v1/` is a byte-preserving copy of the exposed, posthoc Codex evaluation and survey dated 2026-10-27. Its historical statements about publication and annotation describe that earlier activity, not the current publication. It is not a new GPT Web evaluation. Original absolute provenance paths are retained; they are not dependencies of the new portable scoring tool. Third-party paper PDFs are excluded; primary links and actual reading scopes remain in the literature table.

The old evaluation-freeze manifest covers its own original file set. Archive-manifest.json identifies the copied set including the report texts. Do not run old generation/download/scoring scripts in the archive to overwrite preserved scores. The maintained protocol is ../../docs/evaluation/README.md; new labels, if obtained, are separate records.
