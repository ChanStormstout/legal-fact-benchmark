# 来源约束报告评价协议 v1

本协议首次制定于1251841的A0与V38结果已经暴露以后。它是开发侧回顾评价协议，不能叫预注册、独立测试或已验证的法律评分标准。后续新运行必须先冻结问题、允许来源、要点、标注规则、主要指标与停止条件，不能看到结果再改权重。

## 1. 评价对象和单位

评价用户实际可见的报告；候选报告另列。没有进入报告的记录、来源和推导不给报告覆盖分。技术失败和空报告保留在案件分母。主统计单位是独立纠纷，不是句子、随机种子或模型调用。A0只保留一次普通调用，禁止默认为它增添机制。

每案根据问题与允许原文先写参考要点，而不是要求复现一份参考答案。要点应含必要参与者、行为、对象、时间、程序阶段、来源归属和认识状态；原文中的一项当事人主张不等于事实成立，先前法院认定不等于当前法院认可。来源本身支持未决时，正确说明未决原因是可评分内容；明确事实被写成UNKNOWN不得分。

1251841沿用原来十个主题，每个主题拆为两个明确计分条件，总计20分，各条件1分。条件之间不重复奖励；按同一条件评价所有输出。人物身份或法院归属错误另外记录，不能用主题词出现冒充正确答案。涉及同一对象的断言需结合整份报告消歧；报告自相矛盾时，相关要点不能给满分。

## 2. 主指标：正确要点覆盖 R

R = 正确且在可见报告中表达的要点数 / 参考要点总数。

每项只取0或1，不按文风、篇幅或内部ACCEPT评分。正确要点必须有报告原句和允许原文依据。相同要点重复出现只计一次。写错、遗漏、只放在问题标题、只写系统检查失败均不得分。不能通过外部案例记忆或隐藏结局补齐。

必要细节有争议时保留UNRESOLVED标注，计算最低/最高可能分数，不默认为错误，也不伪造满分。新增解释可用同义措辞，不做关键词机械匹配。额外正确内容不强行挤进既有要点，但可单独登记以检查要点清单是否不完整；清单修订必须产生新版本并重评所有方法。

## 3. 配套指标：断言支持率 P 与组合分 F

把报告的实质断言拆为可核对的小命题，包含正文、结论和限制说明；问题标题、格式标签及纯技术失败提示不是事实断言。重复命题先合并。命题需保留否定、条件、归属和指代，不能把“甲法院认为X”拆成无归属的“X”。

每项标签为SUPPORTED、CONTRADICTED、UNSUPPORTED、ANNOTATION_UNRESOLVED。UNSUPPORTED表示允许来源不足以支撑这项明确断言，不等于现实世界已证明其为假。法律推断也必须保留根据和适用范围；不能因为句式像分析就豁免。

P = 得到允许来源支持的去重断言数 / 全部已判定去重实质断言数。

初版另给便于扫描的组合分 F = 100 × 2PR/(P+R)。这是本任务借鉴覆盖/事实性评价后定义的开发侧组合分，不冒充某篇论文的原版官方指标，也不是法律正确性的充分条件。它同时惩罚多写无依据内容和少写重要内容。无实质输出时F=0，P标为不适用；有未裁定标注时给分数区间，不排除争议断言来抬高P。

R衡量需要的内容是否答对，P衡量写出来的内容是否有依据。两者的分母不同，因此F应称“覆盖与支持的调和分”，不是经典集合匹配F1。R是主要任务指标，P、F和严重错误同时公开，不能看到结果后才挑其中一个宣布胜利。法律应用场景没有公认的单一总分；正式研究须在新结果生成前选定最终主要指标和权重。

## 4. 严重错误和主问题正确性

逐项保存严重错误，而不只给一票否决：裁判方向反转、把隐藏目标结局写成已知、关键当事人/法院错绑、无依据的控制性法律结论、遗漏控制性程序门槛。按不同错误事实或决定合并重复措辞，不能把同一错误重复出现算成十个独立错误。普通日期或引用瑕疵另列。

主问题回答状态分为：正确且有依据；方向部分正确但有实质缺失；错误或越过允许来源；没有实质回答。它不是把整份报告按0/1清零。报告仍有错误可以比另一份更好；同样，少写带来的错误减少不自动构成进步。一个方法R更高且P不低、严重错误不增加时，可明确说这些维度更好。维度相互冲突时显示取舍，不在缺少事先权重时事后捏造唯一赢家。

## 5. 专门衡量检查后的处理

正确内容保留率 = 候选中已正确覆盖且交付仍正确覆盖的要点数 / 候选正确覆盖要点数。

错误修复率 = 候选错误中在交付被正确改写的错误数 / 候选错误数。直接删除单独记为错误移除，不冒充修复。同步报告新增正确要点、丢失正确要点、移除错误、新增错误和修订无变化。不能用编辑距离当正确内容保留率；完全不改也可能保留全部错误。

## 6. 引用、成本与评价可信度

引用支持率、重要断言引用覆盖、错误绑定、程序阶段错误、反论覆盖、成本和时间为诊断指标。A0没有被要求程序式引用，所以引用格式不得成为A0和C主质量分的隐性加分项；两者都能用相同允许原文判断语义支持。

程序只核对报告哈希、引用地址、标注来源和算术。判断两句话是否同义、断言是否受来源支持、遗漏是否重要，仍需要语义标注。固定rubric能减少自由裁量并让分数可追查，但不会消灭语义判断和参考选择中的主观性。

本轮标注由Codex依据原文制作，属于非盲、模型来源核对的开发参考，不是独立裁判或人工金标准。正式评价应匿名报告、打乱顺序，在现有授权的GPT网页标注与原文裁定间保留分歧；不向标注者提供内部ACCEPT或方法映射。评价器需另测标签反转、内容删除和法院/角色变换是否引起合理分数变化，这些仅是评价器的离线校验，不能替代被测方法的整案实验。

## 7. 正式比较的边界

本案不能作显著性或泛化结论。后续冻结同一任务与权限，报告纠纷级成对差异和不确定性；不以多次尝试挑最优输出，不将修改前后混为一批。新机制与旧C的保留行为比较是一项独立机制对照；A0仍为一次普通调用。C调用更多可比较完整系统效果，但不能据此宣称同成本优势或将收益单独归因于某个模块。
