## 实现内容

独立模块位于 `legal_bench/historical_contrasts_v1/`。旧代码不修改；
[接口说明](../../docs/HISTORICAL_CONTRASTS_V1.md)和
[运行方法](../../legal_bench/historical_contrasts_v1/README.md)说明全部入口与边界。

| 模块 | 实际功能 |
| --- | --- |
| contracts | 单一接口定义、严格字段/数值校验、版本/哈希、原记录与依赖核对 |
| adapter | 旧来源与 EV/OBJ/USE 全局映射，原数据保留，显式选查询，重查原门禁 |
| provenance | 来源原文件哈希、Unicode 字符与字节片段、文书身份核对 |
| graph | 类型化图、支持/反对/背景关系、绑定节点、原节点/边与张量行号核对 |
| encoder | 本地固定 E5、查询/材料前缀、全部 BPE 窗口、独立 token/位置回放 |
| signatures/ranking | 词法、E5、带符号的提议结构/计数与 RRF；共同候选集合 |
| model | 实际 PyG HeteroConv/SAGEConv，2层128维，固定参数与可追踪采样 |
| contrasts | 来源绑定的路径/结果/区别核对，未知标签保留，TRAIN/DEV 与争议组隔离 |
| pipeline | 检索→排序→待核对对照→原门禁，保存每一步的接口与覆盖 |

GraphSAGE 的检索分数不修改事实、对象绑定或证据资格。支持、反对和背景用途分别
保留，反向消息边不表示法律推导反转。图编号、张量下标与旧局部引用相互独立。
同一材料的两份分包共享来源节点，但不自动合并人物身份、用途或提议。

## 数据接口验收

越界、跨范围引用、节点/边错位、来源变化、过期图/特征/候选、重复 JSON 键、
非法数值、字段遗漏和状态升级均有拒绝测试。多查询旧案例须显式指定 Q1/Q2；
请求中的查询地址须对应实际全局 ISSUE 节点。争议组必须明确声明，不用缺省文书
编号来推断独立争议。TRAIN 标签和生产 SAGE 请求受未完成的结果遮蔽审阅阻断。

真实回放暴露的适配细节已处理：用途方向还包括 CONTEXT，不能丢成支持或反对；
旧案例可能同时保存 Q1/Q2，不能只取数组首项；NOT_ANALYZED 单元若带分析记录，
原值保留但作为状态冲突隔离，不能进入计算。没有修改这些旧答案或其来源。

[22份缓存结果](acceptance/run-f5e75fcb8bd34835/cache-acceptance.json)中，21 份仍为
REJECTED_EVIDENCE_OR_BINDING，1 份仍为 NO_ANALYZED_UNITS。原值与数组顺序完整保存；
被隔离的记录仍在原数据视图中，不能把它们视为从图或案件中“已经不存在”。
缓存保真不意味着其内容正确，也不意味着全部原元数据进入了模型特征。

[原文件检查](acceptance/run-f5e75fcb8bd34835/preservation-check.json)核对 2,542 个
既有代码、缓存、失败输出和入口文件，变更数为零；另冻结 104 个实际来源输入。
原 V20.1 批次保持暂停，当前 V20.4 研究入口保持。新输出根已单独注册，完整材料、
图、编码和 tensor 放在 private 子目录，发布清单排除这些 private 内容。

## 真实案例 569555/P01

[案例摘要](acceptance/run-f5e75fcb8bd34835/real-case-summary.json)记录完整调用链。
历史候选来自另两案 1187427、1954254，共 14 个案例—法律路径单元，
不是 14 个独立案件；范围与路径等价关系尚待核对。
[候选清单](acceptance/run-f5e75fcb8bd34835/candidate-preview.json)保留编号及入选通道。

RRF 与 GraphSAGE 共用同一个候选集合。1,188 个节点的模型输入共 38,759 个 BPE
token，全部编码；保存范围、编码范围和采样范围分别记录。
[编码覆盖](acceptance/run-f5e75fcb8bd34835/coverage-summary.json)包含模型文件哈希和
前缀。2,800 token 的合成超长样例同样完整分段、独立回放；实际模型每次输入
不超过 512。完整 token 消费不证明跨窗口关系已被完整理解。

模型实际执行 PyG 前向计算，参数未更新，状态明确为 UNTRAINED_SMOKE。
它只验证张量、采样、编号、候选与下游契约，没有检索有效性或法律质量结论。
原门禁返回 BINDING_REVIEW_REJECTED，formal_answer=null，自动计算未运行。
本例的正确工程结果是保留问题并阻止它进入推理，不能报告对象绑定已经修复。

历史对照核对接口接受的对照数为零：目前没有本任务经来源核对的路径等价、
对应结果与差异记录。正常门禁通路在明确标注的合成样例中通过，不能替代
真实案例的来源/语义验收。[合成正常路径](acceptance/run-f5e75fcb8bd34835/synthetic-normal-summary.json)。

## 仍需完成的研究工作

需要建设新任务的来源核对参考标签和历史同路径结果对照，核对查询视图中的隐藏
结果与文字线索，再进行授权范围内的训练与同预算比较。旧用途分类标签不适用于
新检索目标。参考可以注明为模型生成并经过来源核对，不能称为人工金标准。

当前提议存在对象/角色/事件语义问题，训练不能替代来源核对。原门禁仍按整个分包
阻断；依赖路径局部放行、完整 counterfactual/questions 流程与律师审批属于后续
主流程整合。本模块不生成事实区别、追问或法律结论，也不改变主线程的这些模块。

依赖实际为 PyTorch 2.8.0、PyG 2.8.1。PyG 与其必要依赖放在项目独立运行目录，
已有环境和模型权重保持。没有下载新的模型权重，没有训练、云端生成、网页标注
或提交推送。只有上述工程行为通过，模型是否提高检索或法律分析仍未验证。
