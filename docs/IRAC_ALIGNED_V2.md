# IRAC alignment v2: concrete bindings and evidence-use limits

This round retains the professor-aligned material-support task, proposed support/opposition
graphs, same-information Flat/two-layer R-GCN, and original ANCO formula. V1 raw data and
failures stay unchanged. The task integrates fallible model proposals; it does not
claim that a GNN independently discovers every legal connection.

Input units are question packets, claims, hashed legal-template versions, tests, and
concrete bindings. Bindings come from independent input tasks. Reference tasks see
permitted sources, legal structure, and neutral object definitions, but no proposed
direction, predictions, or old labels. Existing documents restored79 relevant factual/
prior-proceeding parent passages across seventeen packets, excluding decisive target
analysis; no new targets or authorities.

Original limitations are retained and mapped to uses. A nonempty limitations field no
longer blocks every combination. One link's limitation no longer negates a whole test,
but source review found remaining overbroad combination limits: business-testimony
limitations in188721101 blocked an independent trial finding; a family-dependence gap
in112400 blocked the alternative personal-residence branch. Dependency semantics are
only partly repaired. Date gaps map to temporal tests through still-fallible declarations.
Broad identity/scope flags underwent one independent dependency review and became
specific test-link limits. Original notes, opposing evidence, citation failures, and
review disagreements remain traceable. Model predictions and program-adjusted states
are separate; attached sources are not proof of the model's actual reasoning.

Coverage, binding status, and scope enter numerical metadata; jurisdiction, version,
stage, condition definitions, and rule expressions enter complete text encoding/graphs.
E5 chunks all tokens without node truncation. Unsupported burden rules remain NOT_COVERED;
no invented edges or assumed proof failure.

Splits group disputes/claim types and consider observed tests/states. Some claims have
only two groups, so two folds use no separate early-stopping set. Fixed100 epochs,
three seeds/four trainable methods yield at most24 fits. Conditional priors normalize
by training dispute without target access. Main evaluation requires within-test case
variation in training/holdout and a held-out state observed in training. Other labeled
units are separately reported, not deleted. Unlabeled, UNSUPPORTED, and technical failures
are not negatives.

`scripts/irac_aligned_v2_train.py` atomically saves progress by stage, prioritizes logs/
predictions, then exports/reloads weights to verify probabilities. Shared saving failures
pause dispatch. Synthetic fault injection uses the same scheduler without consuming
real-fit allocations.

In `outputs/gnn-irac-aligned-v2/`, web/ holds raw replies; bindings/ input preparation;
references/ independent model references; graphs/ inputs; freeze/ fixed code/data;
training/ logs; predictions/ probabilities; analysis/ bound conditions/claim combinations;
report-zh.txt conclusions. These exposed development references are not human gold.

All24 fixed fits, six-packet source review, and26 engineering tests completed. Main
evaluation includes128 items/fifteen dispute groups. Flat/graph reference agreement
did not exceed the conditional prior; ANCO had no stable benefit. All claim outputs
remain unresolved from both real evidence gaps and model/combination errors. See
report-zh.txt, comparison.json, and final-source-review.json. Retain general interfaces,
pause GNN expansion. Round ended without SEALED access, full legal answers, parameter
search, or publication.
