# IRAC 对齐 v2：具体绑定与用途限制

本轮沿用老师对齐的材料支持性任务、带支持／反对提议的图、同信息 Flat 与两层 R-GCN，以及原 ANCO 公式。v1 原始资料和失败不改写。研究对象仍是整合可能出错的模型提议，不是 GNN 独立发现全部法律连接。

输入单位是问题包、请求、含内容哈希的法律模板版本、法律检验与具体绑定。输入绑定来自独立输入任务，参考任务只见允许来源、法律结构及中性的对象定义，不见提议方向、模型预测或旧标签。17包已有文书恢复了79个相关事实／既往程序父段，排除目标决定性分析；没有新增目标或法源。

限制保留原版并映射用途，取消“任何非空limitations都挡住整组合”的规则。单条连接限制不再自动否定整个检验，但最终来源审阅发现部分组合级限制仍过宽：188721101中一组经营证言的局限挡住了独立的原审否定认定；112400的家属依赖缺口挡住了自住这一择一分支。因此限制语义仅部分修复，不能宣称所有依赖已正确。日期缺口按声明映射到时间检验，声明本身仍可能错误。身份与规则范围的广泛标记经过一次独立集中依赖审阅，作为具体检验的连接限制。原始备注、反证、引用失败及审阅分歧均可追溯。预测状态与程序作用后的状态分别保存，附带来源不是模型实际依据或法律证明。

法律覆盖状态、绑定状态、适用范围显式进入数值元数据；法域、版本、阶段、条件定义与规则表达进入完整文本编码和图。E5按完整token分块，不截断长节点。缺乏法源的举证规则仍为NOT_COVERED，不造边、不推定举证失败。

划分按纠纷组和请求类型，兼顾已观测检验／状态。少数请求只有两组，采用两折，不另取早停验证集；固定100轮、原三种子、四个可训练方法，共24次拟合上限。条件先验按训练纠纷归一化，不读取目标案件。主评价要求同一检验在训练与留出均有案件差异，且留出状态在训练出现。其他已标单位单列，不删除；未标、UNSUPPORTED与技术失败不作负例。

入口：`scripts/irac_aligned_v2_train.py`。它实际调用分阶段原子保存，逐轮保存进展，优先保存日志与预测，之后导出权重并回读验证概率。共有保存故障暂停后续任务。合成故障注入使用同一调度入口，不占真实拟合预算。

主要文件在 `outputs/gnn-irac-aligned-v2/`：`web/`原回复，`bindings/`输入侧整理，`references/`独立模型参考，`graphs/`输入图，`freeze/`固定方法和数据，`training/`实际训练日志，`predictions/`概率，`analysis/`绑定条件和请求组合，`report-zh.txt`最终范围与结论。参考不是人工金标准；本轮是已暴露材料上的开发验证。

本轮已完成24次固定拟合及六包集中来源审阅，26项相关工程测试通过。主评价128项、15个纠纷组；Flat与图变体的模型参考一致性均未超过条件先验，ANCO没有稳定收益。请求输出仍全部未决，其中既有真实材料缺口，也有模型遗漏与残留组合错误。详见report-zh.txt、comparison.json与final-source-review.json。决定保留通用接口，暂停扩大GNN；本轮已结束，无SEALED访问、完整法律回答、参数搜索或提交推送。
