任务是判决推理重建。原始模型提议、独立参考和用途评价分别保存；参考不能进入自动检查的接受政策。模型给出的用途判断与完整前提状态分开；程序检查地址、显式角色映射、规则版本和逻辑，不批准法律含义。

## 当前入口

- `scripts/proof_semantic_import_v12.py CASE proposal|reference|review RAW`：原始正文另存；仅移除外层JSON围栏；局部规则或用途错误隔离。提议导入后保存输入图、候选、独立检查和完整原始提议，不读取独立参考。
- `scripts/proof_semantic_run_v12.py`：完整依赖搜索，独立进程重算，保存快照、搜索轨迹、检查与限定分析。每请求10000展开或10秒；无默认六候选限制。
- `scripts/proof_semantic_supervision_v12.py --out NEW_DIR`：只读取TRAIN/DEV提议和用途评价，构建独立监督。既有TEST目录不会被此入口打开。缺标签屏蔽；缺QC保持训练关闭。
- `scripts/proof_semantic_train_batch_v12.py --rows ROWS --qc QC --out NEW_DIR`：满足冻结门槛后编码、保存训练冻结并最多执行三方法三种子。默认不运行，不生成TEST法律回答。
- `scripts/proof_semantic_fit_v12.py`：单次固定拟合；先保存训练日志及DEV预测，再导出权重；重载权重生成DEV预测。
- `scripts/proof_semantic_apply_v12.py`：将重载模型的用途概率接入同一搜索与检查入口；不修改证据、原模型完整前提状态或批准字段。
